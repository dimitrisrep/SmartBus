# Το Έξυπνο Τουριστικό Λεωφορείο και οι Αλληλεπιδράσεις του

Ολοκληρωμένη εκπαιδευτική εφαρμογή C# Windows Forms για το μάθημα «Αλληλεπίδραση Ανθρώπου και Υπολογιστή» (2025–2026).

Η εφαρμογή προσομοιώνει ένα έξυπνο τουριστικό λεωφορείο στην Αθήνα. Οι οθόνες Επιβάτη, Οδηγού, Υπαλλήλου και συνεργαζόμενης Καφετέριας μπορούν να ανοίξουν ταυτόχρονα και μοιράζονται την ίδια κατάσταση σε πραγματικό χρόνο.

## Απαιτήσεις

- Windows 10 ή Windows 11
- Visual Studio 2022 Community
- Workload: **.NET desktop development**
- .NET 8 SDK

Δεν απαιτείται εξωτερική βάση δεδομένων ή πρόσθετο NuGet πακέτο.

## Εκτέλεση

1. Αποσυμπιέστε ολόκληρο τον φάκελο.
2. Ανοίξτε το `SmartTouristBus.sln` στο Visual Studio 2022.
3. Περιμένετε να ολοκληρωθεί η φόρτωση της λύσης.
4. Επιλέξτε **Build > Rebuild Solution**.
5. Πατήστε **F5**.

Εναλλακτικά, από Windows Terminal μέσα στον φάκελο:

```powershell
dotnet run --project SmartTouristBus\SmartTouristBus.csproj
```

## Βασικές λειτουργίες

- **Επιβάτης:** θέα της διαδρομής, κοντινά αξιοθέατα με ακρόαση, παραγγελία/πληρωμή με κάρτα, τουριστική πλοήγηση και ασφαλές καταφύγιο σε κακοκαιρία.
- **Οδηγός:** ταχύτητα/όριο, εγκατάλειψη λωρίδας, κόπωση, ασφαλής λειτουργία θυρών και κλιματισμός.
- **Υπάλληλος:** αποκλειστικός χειρισμός οροφής, φωτοβολταϊκά, ενεργειακό ισοζύγιο, καιρός και σκούπα-ρομπότ.
- **Καφετέρια:** ζωντανές παραγγελίες, ορισμός στάσης παράδοσης και ενημέρωση κατάστασης.
- **On-line help:** F1 από κάθε οθόνη, με αυτόματη εμφάνιση του σχετικού θέματος.

## Φωνητική ανάγνωση

Η ακρόαση αξιοθέατων χρησιμοποιεί τη λειτουργία SAPI των Windows. Αν δεν είναι εγκατεστημένη ελληνική φωνή, η εφαρμογή εμφανίζει ενημερωτικό μήνυμα και διατηρεί κανονικά το κείμενο στην οθόνη.

## Σημείωση πληρωμών και GPS

Η πληρωμή και το GPS αποτελούν εκπαιδευτικές προσομοιώσεις. Δεν μεταδίδονται δεδομένα και δεν πραγματοποιείται πραγματική χρέωση ή πλοήγηση. Για επίδειξη κάρτας μπορεί να χρησιμοποιηθεί ο δοκιμαστικός αριθμός `4242 4242 4242 4242`, οποιοδήποτε όνομα, μελλοντική μορφή ημερομηνίας `MM/YY` και τριψήφιο CVV.

## Στοιχεία ομάδας

Πριν από την παράδοση, συμπληρώστε τα ονόματα και τους αριθμούς μητρώου στα εξώφυλλα των δύο εγχειριδίων.
